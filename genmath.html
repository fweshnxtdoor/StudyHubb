Chapter 1: Functions

Functions are a foundational part of mathematics. They model real-world relationships by assigning each input exactly one output. Mastering functions is essential for analyzing mathematical patterns and problem-solving in algebra and calculus.

Unit I. Definition and Representation of Functions

  • A function is a relation where each element of the domain is paired with exactly one element of the range.
  • The domain is the set of all possible input values.
  • The range is the set of all possible output values.
  • Function notation is written as f(x)=expression.
  • Mapping diagrams show how each element of the domain is matched with an element in the range.

Unit II. Types of Functions

  • Linear Function: f(x)=mx+b
  • Quadratic Function: f(x)= ax^2+bx+c
  • Piecewise Function: Defined by different expressions depending on the input interval
  • Constant Function: f(x)=c
  • Identity Function: f(x)=x

Unit III. Operations on Functions

  • Addition: (f+g)(x)=f(x)+g(x)
  • Subtraction: (f−g)(x)=f(x)−g(x)
  • Multiplication: (f⋅g)(x)=f(x)⋅g(x)
  • Division: (f/g)(x) = f(x)/g(x), where g(x)≠0
  • Composition: (f∘g)(x)=f(g(x))
  • Inverse Function: (f^−1)(𝑥), where 𝑓(𝑓^−1(𝑥)) = 𝑥

Unit IV. Graphing Functions

  • The Cartesian plane consists of a horizontal axis (x-axis) and a vertical axis (y-axis).
  • Intercepts are points where the graph crosses the axes.
  • Asymptotes are lines that a graph approaches but never touches.
  • Transformations include:
    • Vertical and horizontal shifts
    • Reflections across the x- or y-axis
    • Vertical and horizontal stretching or compressing

Chapter 2: Interest

Interest calculations are vital in finance. They help us understand how money grows over time. This chapter covers both simple and compound interest, essential in saving, investing, and borrowing.

Unit I. Simple Interest

  • Simple interest is calculated using the formula: 𝐼 = 𝑃𝑟𝑡

    • I: Interest
    • P: Principal
    • r: Annual interest rate (decimal)
    • t: Time in years

Unit II. Compound Interest

  • Compound interest is calculated using the formula: A=P(1+r/n)^nt
  • Where:
    • A: Final amount
    • P: Principal
    • r: Annual interest rate (decimal)
    • n: Number of compounding periods per year
    • t: Time in years
  • Continuous compounding uses: A=Pe^rt

Unit III. Applications of Interest

  • Loan and debt repayment
  • Investment and savings growth
  • Credit card interest accumulation
  • Mortgage and long-term financing calculations

Chapter 3: Propositions

Propositions are statements that are either true or false. This chapter helps students understand logical statements and how they are used in arguments and reasoning.

Unit I. Introduction to Propositions

  • A proposition is a declarative sentence that is either true or false.
  • Examples:
    • "2 + 2 = 4" (true)
    • "The sun is cold" (false)
  • Not propositions:
    • Questions like "Are you there?"
    • Commands like "Close the door."
    • Expressions of opinion like "This is nice."

Unit II. Compound Propositions

  • Compound propositions combine simple statements using logical operators.
  • Conjunction: p∧q
  • Disjunction: p∨q
  • Negation: ∼p
  • Conditional: p→q
  • Biconditional: p↔q

Unit III. Truth Values

  • A contradiction is a statement that is always false.
  • A tautology is a statement that is always true.
  • A contingency is a statement that can be either true or false depending on the truth values of its components.

Chapter 4: Logical Connectives

Logical connectives help link statements to form compound logic. This chapter focuses on constructing and evaluating logical arguments using formal symbols and truth tables.

Unit I. Types of Logical Connectives

  • Negation (∼): Reverses the truth value
  • Conjunction (∧): True only if both statements are true
  • Disjunction (∨): True if at least one statement is true
  • Conditional (→): False only if the first is true and the second is false
  • Biconditional (↔): True when both statements have the same truth value

Unit II. Truth Tables

  • Truth tables help evaluate the truth value of compound logical statements.

Unit III. Applications of Logical Connectives

  • Translating English statements into symbolic logic
  • Constructing and analyzing logical arguments
  • Determining argument validity
  • Identifying logical fallacies
